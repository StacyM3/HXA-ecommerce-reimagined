# HXA-ecommerce-reimagined
## Mobile E-commerce Experience Redesign — Case Study Deck

A product design case study exploring how to improve the mobile shopping experience for **HealthX Africa**, an e-commerce pharmacy platform. The project frames a UX audit and redesign proposal in a Product Manager–style narrative: problem framing → design principles → proposed solution → measurable impact → next steps.

### What's included
An 8-slide `.pptx` presentation covering:
- **The opportunity** — framing the redesign and its goals
- **Current-state audit** — five friction points identified across product discovery, offers, conversion, trust, and mobile UX
- **Current customer journey** — mapped end-to-end (Homepage → Browse → Product → Cart → Checkout)
- **Design principles** — five guiding goals (Discover, Promote, Build trust, Convert, Simplify)
- **Proposed redesign** — annotated homepage concept
- **New shopping flow** — the streamlined journey after redesign
- **Expected impact & measurement** — a metrics framework (conversion rate, cart abandonment, offer CTR, etc.) tied to each objective
- **Next steps** — a concrete ask for validation and stakeholder alignment

### How it was built
The deck was generated programmatically using `pptxgenjs`, with a custom brand color palette, consistent typography, and layout conventions (icon rows, flow diagrams, comparison callouts, and a data table) rather than default PowerPoint templates. Screenshot, mockup, and prototype-video slots are left as clearly marked placeholders for real product assets.

### Why it's structured this way
Rather than presenting redesign work as a purely visual exercise, the deck is structured to read like a PM case study — pairing design rationale with a measurement plan, and being explicit about which claims are observations versus data-backed conclusions.
